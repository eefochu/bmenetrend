# Performance audit — 2026-10-30

**84 distinct retained source-cost findings/opportunities; 13 rejected or merged. The requested 100 validated findings have not been established.** All four requested reviews are complete. These source-cost findings are not independently measured Android bottlenecks.

Four reviewers: Gemini 3.8 Flash Medium, GPT 6 Luna Medium, one GPT 6.1 Sol Medium, and GLM 5.3 Flash Free through OpenCode. The earlier three Sol runs were cancelled after the cost concern. No additional reviewers were started. Existing unrelated edits were preserved.

## Implemented changes

- Catalogue lists and ID lookup maps share source generations across UiState copies. National-ID precedence and old snapshots remain valid. Cache retention is bounded to one generation per type; initial construction remains synchronous.
- Stop-direction suffix list copies removed. Nearest-hit selection uses one pass; native camera/projection/trigonometric invariants read once per tap.
- Loaded basemap reused when returning to the foreground. Native lifecycle regression coverage remains limited to smoke checks.
- Compose crash-report read moved to IO; planner endpoint consolidation runs off Main while preserving raw matches for remote merges.
- Planner countdown runs only when results consume it and lifecycle is STARTED. Route family count cached; heterogeneous lazy rows declare content types; fixed UI regexes hoisted.
- Favourites reuse the shared stop index. SharedStops.resolve now uses a separate snapshot-local alias index, without forcing a boarding index. Exact platform IDs override aliases; duplicate aliases keep their first platform.
- Shared-stop canonicalization reuses timetable objects without alias changes. Route order, loop stop occurrences, times and values are preserved; stop metadata still merges normally.
- Departure calendar results computed once per relevant calendar kind per call. Holiday sets retained only for explicitly reviewed years. Existing timezone and DST behavior preserved.
- Station serving-line cache uses access order, remains bounded to 64 entries, and promotes disk hits.
